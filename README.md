# Projekt_ML
Skrypt pobierający dane znajduje się w pliku download_data.py i zapisuje w folderze data.
Notebooki znajdują się w folderze notebooks zapisują one swoje dane w folderze data.
Do uruchomienia notebooków eda oraz preprocessing potrzebne są dane oryginalne pobierane przez skrypt, zaś notebook models wymaga odpalenia preprocessingu z notebooka preprocessing (wymaga na przykład plików X_test generowanego przez preprocessing).
